# PixelQuest Project Documentation

This folder contains the eight planning and implementation documents for PixelQuest.

- `project-requirements.md` — what to build
- `architecture.md` — how it works
- `design.md` — how it looks
- `phases.md` — implementation roadmap
- `memory.md` — durable project context
- `task-tracker.md` — task-level progress
- `coding-guidelines.md` — rules for AI-assisted coding
- `testing.md` — verification plan

Start with `project-requirements.md`, then `architecture.md` and `design.md`. Use `phases.md` and `task-tracker.md` during implementation. Update `memory.md` after meaningful milestones.
